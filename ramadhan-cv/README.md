# Website CV - Ramadhan Tri Atmojo

Buka `index.html` di browser. Tidak perlu install apa pun (font butuh internet, sisanya offline).

## Fitur
- Transisi halaman "tile dissolve" (menu = pindah halaman, bukan scroll)
- Sphere 3D interaktif di hero, jaringan neural di latar, kursor ring
- Lab: simulator robot Mecanum (WASD/panah, Q/E) + playground jaringan saraf yang dilatih live
- Command palette: Ctrl/Cmd+K atau "/", angka 1-9 untuk loncat halaman
- Terminal interaktif (help, neofetch, matrix, lab, company, ...)
- Bahasa ID/EN

## Mengisi kontak
Edit `js/config.js` (email, GitHub, LinkedIn, Instagram, link CV PDF).

## Perusahaan
Teks PT Vigaro Atmajaya ada di `index.html` (bagian COMPANY) dan `js/main.js` (kunci co_, f1_, rm_). Saat ini tertulis "tahap perencanaan".
