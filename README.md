# Website CV - Ramadhan Tri Atmojo

Buka `index.html` di browser. Tidak perlu install apa pun.
Menu bekerja seperti pindah halaman (dengan transisi), bukan scroll. Tombol Back browser juga berfungsi.

## Mengisi kontak
Edit `js/config.js` (email, GitHub, LinkedIn, Instagram, link CV PDF). Yang dikosongkan tidak ditampilkan.

## Halaman Perusahaan (PT Vigaro Atmajaya)
Teks ada di `index.html` (bagian COMPANY) dan terjemahan di `js/main.js` (kunci co_, f1_, rm_).
Saat ini ditulis sebagai "tahap perencanaan". Ubah setelah perusahaan resmi berdiri.
